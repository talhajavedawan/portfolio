## SmartERP — Enterprise ERP Case Study

From 2019 to 2025, I developed and supported a custom multi-company ERP at MicroKosm used by approximately **200–250 users across multiple businesses**.

### What I worked on

- Built and maintained business-critical features using **C#, .NET Framework, WPF, Entity Framework and SQL Server**.
- Diagnosed and resolved production issues involving application logic, data integrity, performance and integrations.
- Implemented a 15-minute idle-session security feature across **100+ application windows**.
- Built Outlook integration supporting **5,000+ items**.
- Supported modernisation toward **ASP.NET Core, REST APIs, Angular and EF Core**.
- Mentored junior developers and supported technical delivery.
