MSc dissertation · September 2026

Research informing ERP modernisation.

A qualitative case study of a customised desktop ERP for an accounting and finance SME.

Software engineering researchSingle-case evaluation

Customised ERP Solution for Accounting and Finance SMEs

I evaluated the implemented ERP as a software-engineering artefact, using recent academic literature to build a six-dimension framework: functional and accounting alignment; data and process integration; organisational and user fit; security and control; software quality; and modernisation sustainability. I examined the system through technology identification, functional mapping, architectural review, control and quality inspection, and evidence mapping. No human participants were involved.

Findings

The shared data model connects order-to-cash and procure-to-pay with inventory, cost sheets and journal entries, supporting traceability across business processes. The evaluation also identified structural risks in maintainability, authorisation, transaction integrity, testing and credential handling. It distinguishes mechanisms present in the system from controls verified in operation and outcomes demonstrated in use.

Recommended priorities

  • Remediate credential handling and add characterisation tests.
  • Introduce transaction boundaries for multi-step financial operations.
  • Move business rules into an application-service layer and enforce authorisation where operations execute.
  • Expose interfaces selectively, preserving accumulated domain knowledge.

Study limits: The dissertation used code and system evidence. It did not conduct user trials, penetration testing or load testing, and makes no claims about measured user satisfaction, performance or realised financial benefit.
